# Boba Lab

An interactive bubble tea flavor mixer. Choose a base, flavor, sweetness, and toppings to build a custom drink and preview it live.

## Try it

Open `index.html` in a browser. No build tools or dependencies are required.

## Interactions

- Pick a tea base, flavor, sweetness level, and toppings.
- Use mood presets or Surprise me to generate a mix.
- Copy a recipe, save it in the browser notebook, and reload or remove saved mixes.

Saved recipes stay in the current browser using local storage.
